# PARTIE 3: CORRECTIONS PAR CATÉGORIE
# =============================================================================

"""
CATÉGORIE 1: CONDITIONS EVALUATE
---------------------------------
SYMPTÔME: "if True:" ou "elif True:"
CAUSE: Transpileur ne génère pas les conditions depuis WHEN
ACTION: Remplacer par la vraie condition logique

EXEMPLE:
  Avant: if True:
           self.error_code = 'E001'
  Après: if self.trd_quantity == Decimal('0'):
           self.error_code = 'E001'

MÉTHODE:
1. Lire le commentaire COBOL au-dessus de la fonction
2. Identifier la clause WHEN correspondante
3. Traduire la condition en Python
4. Tester avec des valeurs connues


CATÉGORIE 2: AFFECTATIONS MULTIPLES
------------------------------------
SYMPTÔME: Même variable = plusieurs sources différentes
CAUSE: Transpileur génère trop d'affectations
ACTION: Garder uniquement l'affectation correcte

EXEMPLE:
  Avant: self.hold_symbol = self.pos_symbol_key
         self.portfolio_size = self.pos_symbol_key  # ← Erreur type
  Après: self.hold_symbol = self.pos_symbol_key
         # Ligne incorrecte supprimée

MÉTHODE:
1. Identifier le type de la variable cible (Decimal, str, etc.)
2. Vérifier que la source est du même type
3. Supprimer les affectations de types incompatibles
4. L'outil automatique les marque avec "# REMOVED"


CATÉGORIE 3: SEARCH INVALIDES
------------------------------
SYMPTÔME: "if _item == _item:" (toujours True)
CAUSE: Transpileur ne détermine pas la clé de recherche
ACTION: Identifier la vraie clé et corriger

EXEMPLE:
  Avant: for _idx, _item in enumerate(self.ccy_code):
           if _item == _item:
  Après: search_key = self.hold_currency[int(self.hold_idx) - 1]
         for _idx, _item in enumerate(self.ccy_code):
           if _item == search_key:

MÉTHODE:
1. Chercher dans le contexte la variable recherchée
2. Généralement mentionnée dans les commentaires COBOL
3. Extraire la clé AVANT la boucle
4. Comparer _item avec cette clé


CATÉGORIE 4: VARIABLES INEXISTANTES
------------------------------------
SYMPTÔME: AttributeError: 'self.zero' n'existe pas
CAUSE: Transpileur ne convertit pas les mots-clés COBOL
ACTION: Remplacer par la valeur Python équivalente

MAPPING:
  COBOL           →  Python
  ZERO/ZEROS      →  Decimal('0')
  SPACES/SPACE    →  ''
  HIGH-VALUES     →  '\\xff' * 256
  LOW-VALUES      →  '\\x00' * 256

MÉTHODE: L'outil automatique s'en charge


CATÉGORIE 5: LOGIQUE MÉTIER COMPLEXE
-------------------------------------
SYMPTÔME: Code s'exécute mais résultats incorrects
CAUSE: Nuances COBOL perdues lors de la transpilation
ACTION: Révision approfondie fonction par fonction

EXEMPLES:
- Arrondis financiers (ROUNDED)
- Gestion d'overflow (ON SIZE ERROR)
- Ordre d'évaluation (parenthèses)
- Indexation tableaux (1-based → 0-based)

MÉTHODE:
1. Comparer avec le COBOL source ligne par ligne
2. Tester avec jeux de données connus
3. Valider les calculs financiers
4. Documenter les différences
"""

Q: Combien de temps prend la correction complète?
