                               FILE STATUS  IS WS-STATUS-CLIENT.

                               ORGANIZATION IS INDEXED
                               ACCESS MODE  IS DYNAMIC

                               ORGANIZATION IS SEQUENTIAL
                               ACCESS MODE  IS SEQUENTIAL
                               FILE STATUS  IS WS-STATUS-TRANS.

      ******************************************************************
      * PROCEDURE DIVISION
      * Contient la logique métier avec ses vulnérabilités
      ******************************************************************
       PROCEDURE DIVISION.
       0000-MAIN.
           PERFORM 1000-INITIALISATION
           PERFORM 2000-TRAITEMENT-PRINCIPAL
           PERFORM 9000-FIN-PROGRAMME
           STOP RUN.

       1000-INITIALISATION.
           DISPLAY '*** SYSTEME BANCAIRE v1990 ***'
           DISPLAY 'INITIALISATION EN COURS...'
           
           MOVE FUNCTION CURRENT-DATE(1:8) TO WS-DATE-COURANTE
           MOVE FUNCTION CURRENT-DATE(9:6) TO WS-HEURE-COURANTE
           
           OPEN I-O   F-CLIENTS
                I-O   F-COMPTES
                INPUT F-TRANSACT
                OUTPUT F-REPORT
           
           IF WS-STATUS-CLIENT NOT = '00'
               DISPLAY 'ERREUR FICHIER CLIENTS: ' WS-STATUS-CLIENT
               MOVE 'O' TO WS-ERREUR-FLAG
           END-IF
           
           DISPLAY 'INITIALISATION TERMINEE A '
                   WS-HEURE-HH ':' WS-HEURE-MN.

       2000-TRAITEMENT-PRINCIPAL.
           DISPLAY 'DEBUT TRAITEMENT PRINCIPAL'
           
           PERFORM 2100-CHARGER-DONNEES
           PERFORM 2200-TRAITER-TRANSACTIONS
           PERFORM 2300-CALCULER-INTERETS
           PERFORM 2400-GENERER-REPORT-FISCAL
           PERFORM 2500-AUDIT-SECURITE
           
           DISPLAY 'TRAITEMENT TERMINE'.

       2100-CHARGER-DONNEES.
           DISPLAY 'CHARGEMENT DONNEES EN MEMOIRE...'
           MOVE 1 TO IDX-CLIENT
           
           MOVE ZERO TO F-CLIENT-ID
           START F-CLIENTS KEY IS NOT LESS THAN F-CLIENT-ID
           
           PERFORM UNTIL WS-STATUS-CLIENT = '10' OR IDX-CLIENT > 1000
               READ F-CLIENTS NEXT RECORD
                   AT END CONTINUE
               NOT AT END
                   MOVE F-CLIENT-ID TO WS-TAB-CLIENT-ID(IDX-CLIENT)
                   MOVE F-CLIENT-NOM TO WS-TAB-CLIENT-NOM(IDX-CLIENT)
                   ADD 1 TO IDX-CLIENT
               END-READ
           END-PERFORM
           
           DISPLAY IDX-CLIENT ' CLIENTS CHARGES'.

       2200-TRAITER-TRANSACTIONS.
           DISPLAY 'TRAITEMENT DES TRANSACTIONS...'
           MOVE 'N' TO WS-FIN-FICHIER
           
           PERFORM UNTIL WS-FIN-FICHIER = 'Y'
               READ F-TRANSACT
                   AT END
                       MOVE 'Y' TO WS-FIN-FICHIER
                   NOT AT END
                       PERFORM 2210-TRAITER-TRANSACTION
               END-READ
           END-PERFORM.

       2210-TRAITER-TRANSACTION.
      * VULNERABILITE : PAS DE VALIDATION DU MONTANT
           IF F-TRANS-MONTANT > 1000000
               DISPLAY 'ALERTE: GROSSE TRANSACTION - ' F-TRANS-COMPTE
           END-IF
           
      * VULNERABILITE SQL INJECTION (LIGNE CRITIQUE)
           MOVE F-TRANS-COMPTE TO WS-ACCOUNT-NO
           STRING 'SELECT * FROM comptes WHERE numero = '''
                   DELIMITED BY SIZE
                   WS-ACCOUNT-NO
                   DELIMITED BY SIZE
                   ''''
                   DELIMITED BY SIZE
                   INTO WS-SQL-QUERY
           
           DISPLAY 'REQUETE SQL GENERE: ' WS-SQL-QUERY(1:50)
           
      * MAJ DU COMPTE (LOGIQUE OBSOLETE)
           MOVE F-TRANS-COMPTE TO F-COMPTE-NUM
           READ F-COMPTES
               INVALID KEY
                   DISPLAY 'COMPTE INCONNU: ' F-TRANS-COMPTE
               NOT INVALID KEY
                   PERFORM 2215-MAJ-SOLDE
           END-READ.

       2215-MAJ-SOLDE.
      * CALCUL ANCIEN (1995)
           IF TRANS-DEPOT
               ADD F-TRANS-MONTANT TO F-COMPTE-SOLDE
           ELSE
               IF TRANS-RETRAIT
                   SUBTRACT F-TRANS-MONTANT FROM F-COMPTE-SOLDE
               END-IF
           END-IF
           
      * APPLIQUER DECOUVERT (TAUX 1995)
           IF F-COMPTE-SOLDE < 0
               COMPUTE WS-FRAIS = 
                   ABS(F-COMPTE-SOLDE) * 0,0015
               SUBTRACT WS-FRAIS FROM F-COMPTE-SOLDE
               DISPLAY 'FRAIS DECOUVERT: ' WS-FRAIS
           END-IF
           
           REWRITE F-ENREG-COMPTE.

       2300-CALCULER-INTERETS.
           DISPLAY 'CALCUL DES INTERETS (METHODE 1995)...'
           
           PERFORM VARYING WS-I FROM 1 BY 1
                     UNTIL WS-I > 1000
               PERFORM 2310-CALCUL-INTERET-COMPTE
           END-PERFORM.

       2310-CALCUL-INTERET-COMPTE.
      * FORMULE OBSOLETE : INTERETS SIMPLES
           IF COMPTE-EPARGNE
               COMPUTE WS-INTERET = 
                   F-COMPTE-SOLDE * WS-TAUX-INTERET-1995 / 12
               ADD WS-INTERET TO F-COMPTE-SOLDE
           ELSE
               IF F-COMPTE-SOLDE > 10000
                   COMPUTE WS-INTERET = 
                       F-COMPTE-SOLDE * 0,0005
                   ADD WS-INTERET TO F-COMPTE-SOLDE
               END-IF
           END-IF.

       2400-GENERER-REPORT-FISCAL.
           DISPLAY 'GENERATION RAPPORT FISCAL 1995...'
           
           PERFORM VARYING WS-I FROM 1 BY 1
                     UNTIL WS-I > 1000
               MOVE WS-TAB-CLIENT-ID(WS-I) TO F-CLIENT-ID
               READ F-CLIENTS
                   NOT INVALID KEY
                       PERFORM 2410-CALCULER-IMPOT
                       PERFORM 2420-ECRIRE-LIGNE
               END-READ
           END-PERFORM.

       2410-CALCULER-IMPOT.
      * CALCUL IMPOT OBSOLETE 1995
           MOVE F-CLIENT-SALAIRE TO WS-REVENU-ANNUEL
           MULTIPLY 12 BY WS-REVENU-ANNUEL
           
           EVALUATE TRUE
               WHEN WS-REVENU-ANNUEL <= WS-TRANCHE1-LIM
                   COMPUTE WS-IMPOT-CALCULE = 
                       WS-REVENU-ANNUEL * WS-TAUX-TRANCHE1
               WHEN WS-REVENU-ANNUEL <= WS-TRANCHE2-LIM
                   COMPUTE WS-IMPOT-CALCULE = 
                       WS-TRANCHE1-LIM * WS-TAUX-TRANCHE1 +
                       (WS-REVENU-ANNUEL - WS-TRANCHE1-LIM) 
                       * WS-TAUX-TRANCHE2
               WHEN OTHER
                   COMPUTE WS-IMPOT-CALCULE = 
                       WS-TRANCHE1-LIM * WS-TAUX-TRANCHE1 +
                       (WS-TRANCHE2-LIM - WS-TRANCHE1-LIM) 
                       * WS-TAUX-TRANCHE2 +
                       (WS-REVENU-ANNUEL - WS-TRANCHE2-LIM) 
                       * WS-TAUX-TRANCHE3
           END-EVALUATE
           
      * AJOUTER COTISATIONS SOCIALES OBSOLETES
           COMPUTE WS-COTISATIONS = 
               WS-REVENU-ANNUEL * 0,172
           ADD WS-COTISATIONS TO WS-IMPOT-CALCULE.

       2420-ECRIRE-LIGNE.
           MOVE F-CLIENT-ID TO WS-OUTPUT-ID
           MOVE F-CLIENT-NOM TO WS-OUTPUT-NOM
           MOVE WS-REVENU-ANNUEL TO WS-OUTPUT-REVENU
           MOVE WS-IMPOT-CALCULE TO WS-OUTPUT-IMPOT
           WRITE F-LIGNE-REPORT FROM WS-LIGNE-OUTPUT.

       2500-AUDIT-SECURITE.
           DISPLAY 'AUDIT DE SECURITE...'
           
      * VULNERABILITE BUFFER OVERFLOW
           MOVE SPACES TO WS-AUDIT-RECORD
           STRING 'Transaction: ' DELIMITED BY SIZE
                   F-TRANS-COMPTE DELIMITED BY SIZE
                   ' Montant: ' DELIMITED BY SIZE
                   F-TRANS-MONTANT DELIMITED BY SIZE
                   ' Description: ' DELIMITED BY SIZE
                   F-TRANS-DESC DELIMITED BY SIZE
                   INTO WS-AUDIT-RECORD
           
           DISPLAY 'AUDIT: ' WS-AUDIT-RECORD(1:70).

       9000-FIN-PROGRAMME.
           DISPLAY '*** FIN DU PROGRAMME ***'
           DISPLAY 'RAPPORT FINAL:'
           DISPLAY '- Traitement termine avec succes'
           
           CLOSE F-CLIENTS
                 F-COMPTES
                 F-TRANSACT
                 F-REPORT
           
           IF ERREUR-DETECTEE
               DISPLAY 'ATTENTION: ERREURS DETECTEES'
               MOVE 8 TO RETURN-CODE
           ELSE
               DISPLAY 'SUCCES COMPLET'
               MOVE 0 TO RETURN-CODE
           END-IF.

      ******************************************************************
      * SOUS-PROGRAMMES COMPLEXES
      ******************************************************************
       5000-CALCUL-COMPLEXE.
      * ALGORITHME COMPLEXE OBSOLETE
           MOVE 1 TO WS-COMPTEUR
           PERFORM VARYING WS-I FROM 1 BY 1
                     UNTIL WS-I > 100
               COMPUTE WS-RESULTAT = WS-I * WS-PI
               PERFORM 5100-SOUS-CALCUL
           END-PERFORM.

       5100-SOUS-CALCUL.
           ADD 1 TO WS-COMPTEUR
           IF WS-COMPTEUR > 50
               MOVE 1 TO WS-COMPTEUR
           END-IF.

       6000-GESTION-ERREURS.
      * GESTION ERREURS BASIQUE
           DISPLAY 'ERREUR DETECTEE'
           DISPLAY 'CODE: ' WS-ERREUR-CODE
           DISPLAY 'MESSAGE: ' WS-ERREUR-MSG.

       7000-UTILITAIRES.
       7100-FORMATER-DATE.
           MOVE WS-DATE-JJ TO WS-DATE-OUT-JJ
           MOVE WS-DATE-MM TO WS-DATE-OUT-MM
           MOVE WS-DATE-AAAA TO WS-DATE-OUT-AAAA.

       7200-VALIDER-MONTANT.
      * VALIDATION TRES BASIQUE
           IF WS-MONTANT < 0
               DISPLAY 'ERREUR: MONTANT NEGATIF'
           END-IF
           IF WS-MONTANT > 9999999
               DISPLAY 'ALERTE: MONTANT TROP ELEVE'
           END-IF.

       END PROGRAM BANQUE-CENTRALE-SYSTEM.
