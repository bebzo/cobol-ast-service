Votre cobol-ast-service contient probablement :

typescript
// api/parse.ts (Vercel Edge Function)
export const config = {
  runtime: 'edge',
};

export default async function handler(req: Request) {
  const { cobolCode } = await req.json();
  
  // Parse COBOL to AST
  const ast = parseCobolToAST(cobolCode);
  
  // Extract structure
  const structure = analyzeStructure(ast);
  
  return new Response(JSON.stringify({
    ast,
    structure,
    modules: structure.modules,
    complexity: calculateComplexity(ast),
    lineCount: cobolCode.split('\n').length
  }), {
    headers: { 'Content-Type': 'application/json' }
  });
}
```

**Flow complet :**
```
1. User uploads COBOL dans UI
2. Frontend → Supabase Function
3. Supabase → cobol-ast-service.vercel.app/api/parse
4. AST Service parse COBOL
5. AST Service → return structure
6. Supabase → Gemini avec AST context
7. Gemini → generate Python
8. Supabase → return à Frontend
9. Frontend → display results
