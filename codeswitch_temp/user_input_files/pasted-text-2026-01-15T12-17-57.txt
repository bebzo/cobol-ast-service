**Suggestions de Code**

Voici un exemple de modification pour standardiser l'arrondi sur `ROUND_HALF_EVEN` :

```python
from decimal import Decimal, ROUND_HALF_EVEN

def round_to_even(value, decimal_places=2):
    """
    Arrondit une valeur à un nombre spécifié de décimales en utilisant l'arrondi bancaire (ROUND_HALF_EVEN).
    """
    quantizer = Decimal('0.' + '0' * decimal_places) if decimal_places > 0 else Decimal('1')
    return Decimal(value).quantize(quantizer, rounding=ROUND_HALF_EVEN)

# Exemple d'utilisation:
amount = Decimal('123.455')
rounded_amount = round_to_even(amount, 2)
print(rounded_amount) # Output: 123.46

```
